# Estruturas de Dados — 2026

Repositório de atividades acadêmicas em **linguagem C**, voltadas a fundamentos de estruturas de dados, memória e ponteiros.

## Conteúdo

- [Atividades em sala](Atividade%20Sala/Atividade%20Sala/) — exercícios em C.
- [Treinamento de ponteiros](Treinamento%20de%20ponteiro/) — prática com alocação e `realloc`.

## Como executar

Compile cada arquivo `.c` individualmente com GCC ou seu ambiente de desenvolvimento C. Exemplo:

```bash
gcc "Treinamento de ponteiro/Treinamento Realloc.c" -o treino
```

O código original foi mantido como registro do aprendizado.
